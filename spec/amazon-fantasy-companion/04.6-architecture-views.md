### 4.6 Architecture views

Every figure is a derived projection of the supplied models.

Table (T4): View provenance

| Spec figure | Native/view source | Omission / interpretation |
|---|---|---|
| system-context, structure | AFC-Structure / V-ST3b-1 | Groups owned parts; no claim of deployed resources |
| interfaces, watch-flow | AFC-Interfaces / V-ST3b-2 and AFC-States | Sequence combines named boundaries; no latency guarantees |

| data | AFC-Data / V-ST3b-4 | Logical dependencies; field detail stays in dictionary |

Model provenance is fixed by the digest in 1.2.1. Figures use editable YAML rendered into SVG and draw.io with the vendored kit; those are derived architecture drawings, not new SysML source. The original [model SVG views](../../docs/plans/2026-10-12-amazon-fantasy-companion-phase-2/models/views.md) remain the source views. A rebuild of the Markdown does not itself rerender diagrams; the verification workflow renders and lints them separately.

Figure lint checks layout, and trace inspection checks correspondence to the cited model sources and SD-035 annotations. For AFC-PR-041 and AFC-PR-047, neither test establishes video integration; only the real-stick composition/fallback evidence does.
