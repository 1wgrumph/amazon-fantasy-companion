#### 4.1.99 Allocation

The native allocation table remains the authority for every model-element binding.

[allocation.md](../../docs/plans/2026-10-12-amazon-fantasy-companion-phase-2/models/allocation.md) maps the original 65 UIDs to structure, interface, state and data elements. It predates SD-035: AFC-PR-066 is allocated to PROFILE and LINEUP by the current register, while the three withdrawn UIDs retain their historical model links. Appendix A covers all 66 register UIDs. This table maps the planned realization boundaries without asserting code exists.
