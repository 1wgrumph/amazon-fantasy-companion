#### 4.1.2 Lineup source and scoring

**BLUF:** One selected lineup source feeds both relevance matching and panel scoring.

**Frame**

- **Who:** Product implementation and verification teams.
- **What:** Lineup source and scoring.
- **Why:** Preserve the approved experience and its evidence boundaries.
- **How:** Apply the cited register and model contracts.
- **When:** Phase 2 implementation and subsequent verification.
- **Where:** Fire TV companion and AWS backend.

`backend.lineup` owns the source switch. At T_yahoo without approval it accepts manual lineups constructed from ESPN rosters and labels them manual. The switch replaces active source selection atomically from consumers' perspective; it must not mix Yahoo scoring with manual lineups or leave two active sources. Pre-link/unconfigured setup is not an active configured lineup.

Yahoo uses league scoring settings. Manual scoring uses a documented default statistic/coefficient table and the display label “Default scoring”. That table is a visible Phase 2 design input, not fabricated here. Starter changes propagate to panel and policy using the same new lineup revision. A source change or correction invalidates derived panel values before refreshed values are displayed.
