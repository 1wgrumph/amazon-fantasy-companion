# amazon-fantasy-companion

Fire TV fantasy-sports companion for the Build, Ship, Shape: Amazon Developer
Hackathon 2026. Personalized alerts tied to the viewer's Yahoo Fantasy
starters, a right-side lineup panel beside unobscured playback, and supported
game/channel handoff.

Status: planning. Product intent is tracked in issue #1; the architecture,
program plan, and milestones land under `docs/plans/`.
