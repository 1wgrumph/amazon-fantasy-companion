# RW1 evidence projections

These are selected operational records for the M03–M05 recovery candidate.
`manifest.json` binds every private original to its projected SHA-256. Only
machine paths and private network identifiers were replaced. Original hashes,
IDs, dates, verdicts and limitations are retained; original controller records
and the approved planning package remain unchanged. These copies are not
operational profile bindings or replacements for canonical planning hashes.

Safe synthetic captures accompany this package under the recovery evidence
folders. Linking-code captures, credentials, raw sessions, provider history
and generated binaries are excluded. The presentation HTML is a CSS-only
derivative; its original and derivative hashes are recorded in the source map.

Author PASS records are not independent acceptance. The scheduled RW1 review,
selected OCR coverage assistance and claim-specific Reverify disposition remain
required. Future live TNF and Vega obligations remain open. This package grants
no publication or activation authority.
