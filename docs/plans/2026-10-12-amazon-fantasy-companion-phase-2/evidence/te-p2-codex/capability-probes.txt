usage: reverify [-h]
                {auto,parse-pe,pattern-scan,strings,diff-patch,disasm,decode-protobuf,decode-tlv,emulate,parse,backends,gen-hook,hexdump,reconstruct,functions,orchestrate,ledger,verify,audit-boundary,rollover}

Reverify - verified reverse engineering, protocol dissection, and emulation
toolkit

positional arguments:
  {auto,parse-pe,pattern-scan,strings,diff-patch,disasm,decode-protobuf,decode-tlv,emulate,parse,backends,gen-hook,hexdump,reconstruct,functions,orchestrate,ledger,verify,audit-boundary,rollover}
    auto                Automatically triage and inspect target binary
    parse-pe            Parse PE32/PE32+ binary structure
    pattern-scan        Scan binary data for AOB hex pattern with wildcards
    strings             Extract ASCII and Unicode strings from binary
    diff-patch          Compare original and patched binaries and output patch
                        diff
    disasm              Disassemble binary code or hex stream
    decode-protobuf     Dissect raw Protobuf binary stream
    decode-tlv          Dissect TLV binary packet
    emulate             Emulate instruction execution
    parse               Parse PE, ELF or Mach-O: arch, entry, sections,
                        imports, exports
    backends            Show which engines are active (capstone / unicorn /
                        lief)
    gen-hook            Generate Frida hook script
    hexdump             Display formatted hexadecimal dump
    reconstruct         Closed loop: model proposes claims, the tools verify,
                        iterate until grounded
    functions           List recovered functions: angr when installed,
                        otherwise only the entry point and exports
    orchestrate         Run a goal across fresh-context sessions: the model
                        asks for rollovers, the hand-off is verified from the
                        ledger
    ledger              Durable ledger of grounded facts per binary - the
                        state that survives /clear, compaction and restarts
    verify              Verify claims about a binary against the deterministic
                        tools (the core Reverify loop)
    audit-boundary      Audit filesystem path and network SSRF boundaries
    rollover            Rollover for Claude Code / Codex / Gemini CLI /
                        OpenCode: hooks that hand off to files instead of
                        compacting, and a launcher that replaces the session
                        with a fresh one

options:
  -h, --help            show this help message and exit
exit=0
