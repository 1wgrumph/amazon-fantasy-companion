## Residual risk (existing, not introduced)
Linking by code alone, with no login, is still open to remote phishing. An attacker can send a victim a live code. If the victim ignores the warning and confirms within the code's lifetime (600 s by default), the attacker's TV gets a session.
- The profile field on the link page is free text, so whoever confirms picks which profile the TV links to.

Both follow from the DEC-AFC-SD-048 design. Fully closing this would need user authentication, which that decision rules out. The warning only reduces the risk.
