3Outcome, scope, exclusions, and Definition of Done

Planned outcome

A customer-configurable Fire TV companion, built for the Amazon Developer Hackathon Fire TV track and the AWS Builder mini challenge (SD-008), that notices NFL moments relevant to the viewer's fantasy starters, alerts the viewer while another viewing app plays, helps the viewer reach the game in a provider app the viewer already uses, and shows a right-side lineup panel beside unobscured video. It retains experience items 1, 2, 3, 4 and 6 of issue #1 plus the right-side panel, and excludes every messaging and community feature. It runs on the owner's 2018 Fire TV stick on Fire OS from the `AmazonAppDev/hello-world-fire-tv` starter (SD-001, SD-003), reads live NFL data from ESPN's unofficial public JSON (SD-004), reads lineups from Yahoo or, from T_yahoo without approval, from labeled manual entry (SD-007), and runs its backend on an owner-created AWS Free-plan account (SD-005). The panel route is decided by a spike bounded by spike_panel_max; on failure the panel runs beside the app's own player with labeled open-licensed footage (Mode A, SD-006, SD-006a).

Scope

  • Retained experience items 1, 2, 3, 4, 6 of issue #1 plus the right-side lineup panel on the owner's Fire TV stick
  • D1 architecture specification written with D5
  • D2 program plan and D3 GitHub milestones
  • D4 shared CI/CD capability and harness hooks in Alphazedehq
  • D5 shared spec-authoring skill in Alphazedehq
  • Vnv guidance tree, local plus Actions gate, Scribe developer-feedback deliverables
  • Submission materials (owner submits)

Exclusions

  • Messaging, message boards, community rooms, shared chat and watch-party social features (issue #1, owner 2026-10-10).
  • Hardware performance benchmarking or measured device latency, frame rate or memory claims (issue #1 §Lightweight device design).
  • Vega OS builds, a second device, any device purchase (SD-003).
  • NFL broadcast footage or highlights (SD-006a).
  • Paid AWS resources or a plan upgrade (C4); paid Actions overage (C11).
  • Alexa+ track, Open Source mini challenge (SD-008); Alexa voice unless implemented and verified (C8).
  • Copying the GridMarket kit into this repository as project-local skills (SD-013, superseded by SD-022); this repository receives only the vendored scripts of the shared D5 skill.
  • Generative AI commentary unless the owner selects it at the integrated review (coverage ledger: `typesafe-ai` deferred). Recommendation: exclude.
  • Automatic channel switching without the customer's configured confirmation (issue #1 §Proposed standout moment).
  • Any owner-only action: license choice, visibility flip, video upload, Devpost submission, reviewer access, external feedback, AWS account and credential creation, Yahoo application (C9).
