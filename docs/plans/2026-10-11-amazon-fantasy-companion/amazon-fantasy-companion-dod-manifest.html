3Outcome, scope, exclusions, and Definition of Done

Planned outcome

Phase 1 of the spec-first order (DEC-AFC-SD-023): D5 — one shared, repo-agnostic `spec-authoring` skill in the owner’s shared skills, generalized from the GridMarket spec kit; D4 — the shared, repo-agnostic CI/CD capability (`setup-pre-commit`, `setup-a-repo`, `ship-pull-request` extended, harness hooks calling the one gate entrypoint); this repository usable with them (one gate entrypoint with `spec`, `docs`, `hygiene` areas, vendored D5 tools, Vnv guidance tree); Scribe developer-feedback log started; the Phase 1 spec track ST-1..ST-5 (requirements register, SysML v2 models, D1 with D5, owner spec review) and the Phase 2 sequence P2-6..P2-7 planned with entry criteria.

Scope

  • D5 shared spec-authoring skill in Alphazedehq (S06), linked into harness skill directories (S06L, S11)
  • D4 shared CI/CD skill extensions in Alphazedehq (S01, S02, S03) and harness hooks (S11T, S11); thin entry skill S41 (OD-AFC-01 = B, owner 2026-10-16)
  • This repository gate entrypoint with spec, docs, hygiene areas, local hooks and Actions workflow (S09T, S09)
  • Vendored D5 tools in tools/spec/ with MIT notices (S42)
  • Vnv guidance tree for the Phase 1 areas (S07)
  • Scribe developer-feedback log start (S08)
  • Phase 1 spec track ST-1..ST-5 and Phase 2 sequence P2-6..P2-7 with entry criteria (planned here, not sliced)

Exclusions

  • All product implementation work in Phase 1: TV app, backend, device spikes, ESPN capture, submission material (DEC-AFC-SD-023). It moves to Phase 2. Product requirements, models and D1 move to the spec track.
  • GitHub milestone creation in Phase 1. D3 is created only after the Phase 2 plan is approved (DEC-AFC-SD-023).
  • Copying the GridMarket kit into this repository as project-local skills (SD-013, superseded by SD-022). This repository gets only the vendored scripts of the shared D5 skill.
  • Messaging, message boards, community rooms, shared chat and watch-party social features (issue #1, owner 2026-10-10). This still holds for the spec track and Phase 2.
  • Paid Actions overage (C11).
  • Any owner-only action: license choice, visibility flip, external feedback, credential creation (C9).
